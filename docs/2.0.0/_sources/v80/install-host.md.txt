# AMR Installing the Deployment package onto the Host Server

1.  Before AMR installation, ensure that the Xilinx RunTime library (XRT) has been removed. It’s impossible to have AMR management interface (AMI) and XRT running on the same host simultaneously.

    **Ubuntu:**

    ```bash
    # Check if XRT is installed
    apt list | grep xrt

    # Remove XRT if present
    sudo apt remove xrt
    ```

    **RHEL:**

    ```bash
    # Check if XRT is installed
    yum list | grep xrt

    # Remove XRT if present
    sudo yum remove xrt
    ```

2.  Unzip the deployment archive

    unzip amd_v80_gen5x8_25.1_xbtest_stress_20251113.zip

3.  Change the directory into the folder that was created during the unzip

    cd amd_v80_gen5x8_25.1_xbtest_stress_20251113

4.  Run the AMR\_install bash script

Note: this will need to be run as sudo.

    sudo ./amr_install.sh

The AMR\_install script will perform the following tasks:

  - Remove any previous AMR deployment installations (including AMI and xbtest software installations).

  - Copy AMR deployment archive contents (excluding sw\_packages) to the **/opt/amd/amr/\<AMR Design Name\>/** directory. The *AMR Design Name* for this example is *amd\_v80\_gen5x8\_25.1\_xbtest\_stress*.

  - Install the AMI & xbtest software packages.
