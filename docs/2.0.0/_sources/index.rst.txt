=================
AMR
=================

Welcome to the Adaptive Management Runtime (AMR) documentation. AMR provides comprehensive management capabilities for Alveo and Embedded+ boards featuring Versal devices connected to x86 hosts via PCIe.

This documentation covers the complete AMR ecosystem including hardware design, firmware architecture, software services, deployment procedures, and board-specific information.
