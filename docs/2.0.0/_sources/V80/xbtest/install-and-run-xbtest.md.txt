# How-to Install and Run xbtest on V80 Card

<span id="how-toinstallandrunxbtestonv80card-note"></span>

## Important Note

**xbtest is not supported with AMR in this release.**

For xbtest functionality on V80 cards, you must use the AVED 2025.2 release instead of AMR.

Please refer to the AVED documentation for complete xbtest installation and usage instructions:

**AVED xbtest Documentation:**
