# V80 Board Documentation

This section contains comprehensive V80-specific documentation including hardware design, software services, installation guides, deployment, and testing.

## V80 Board Overview

The V80 is a PCIe accelerator card featuring the Versal V80 HBM-series device. The board provides high-performance computing capabilities with hardened PCIe Gen5 connectivity and high-bandwidth memory resources optimized for data center and cloud deployments.

The V80 includes CPM5 (Coherent PCIe Module) which integrates PCIe Gen5 x8 controller and QDMA functionality in hardened silicon. The device also features 32 GB of integrated HBM (High-Bandwidth Memory) providing exceptional memory bandwidth for compute-intensive workloads.

## V80 Key Features

- **CPM5 Hardened PCIe**: Gen5 x8 controller with integrated QDMA DMA engine in silicon
- **HBM High-Bandwidth Memory**: 32 GB organized as two 16GB stacks (~460 GB/s bandwidth)
- **Memory Capacity**: 68 GB total (32GB HBM + 32GB DDR4 DIMM + 4GB Discrete DDR)
- **Performance**: ~32 GB/s PCIe bandwidth, ~460 GB/s HBM bandwidth

## V80 Target Applications

The V80 Board is optimized for data center and cloud computing environments requiring maximum performance. Target applications include:

- **AI and Machine Learning Inference**: Workloads that benefit from high memory bandwidth
- **Video Processing Pipelines**: Applications demanding both PCIe and memory throughput
- **High-Performance Computing**: Tasks requiring large memory capacity
- **Multi-Tenant Cloud Services**: Cloud service providers leveraging V80 for inference services
- **Enterprise Analytics**: Data centers deploying for analytics and processing workloads

## Technical Specifications Summary

| **Property** | **Value** |
|--------------|-----------|
| **Device** | Versal V80 (xcv80-lsva4737-2MHP-e-S) |
| **PCIe Interface** | Gen5 x8 (32 GT/s raw speed, ~32 GB/s bandwidth) |
| **PCIe Functions** | PF0: 0x50b4 (Management), PF1: 0x50b5 (User/DMA) |
| **HBM Memory** | 32 GB (two 16GB stacks, ~460 GB/s bandwidth) |
| **DDR4 DIMM** | 32 GB RDIMM |
| **Discrete DDR4** | 4 GB (for firmware and control) |
| **Total Memory** | 68 GB |
