# AMI Architecture

<span id="amiarchitecture-overview"></span>

## Overview

The AMR Management Interface (AMI) provides host-access to control and manage the [AMR Management Controller](../firmware/amc-architecture/) (AMC).

It consists of:

  - A kernel driver, providing access to the AMR platform.

  - An API, providing a user-space abstraction to the kernel driver.

  - A command line tool ([ami\_tool](../../deployment/ami-tool-guide)), providing a human-readable interface to the API.

Note: The AMI is an **example** design demonstrating how an AMR host might look and be developed. It is **not** intended to be the final word in AMR run time management and control.
