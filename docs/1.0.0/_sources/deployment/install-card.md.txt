# AMR Installing the Design onto the Card

After installing the AMR Deployment package onto the Host, the next step is to update the design in the OSPI flash of the AMD Alveo™ card.

As the FPT in the new AMR Deployment package may not align with the FPT that is currently on your card, it is important that you update the OSPI flash with the FPT Setup PDI over JTAG using the AMD Vivado™ HW manager. This will ensure that the correct FPT is in flash.

The steps to do this are found in [Updating AMR FPT Image in Flash](../update-fpt/).

In general, when the FPT is known to be the same, it is also possible to update the AMR design over PCIe® using the AMI tool. In this case, the design.pdi from the installed deployment is used instead of the fpt\_setup pdi. Only the PDI\_BOOT partition is updated in flash ](not the FPT).

The steps to do this are found in [AMR Updating Design PDI in Flash](../update-pdi/).

**Note:** Especially when picking up a new card, it’s worth noting that the deployment archive will always contain a version of AMI which is compatible with the AMC FW which is in the fpt\_setup pdi. To avoid any confusion, updating the fpt\_setup PDI over JTAG is the simplest and recommended approach.
